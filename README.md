# Algo-vis
- An Algorithm visualizer that measures how fast your favourite sorting algorithm is!
- The Project was made using HTML5 Canvas and JS, alongside some CSS styling
- The purpose of the project is to learn how sorting algorithms work and compare them visually.
- I really enjoy how it looks!!
- The project features three sorting algorithms: Quicksort(end pivot), Merge Sort, and Bubble Sort.
- You can increase or decrease the number of elements sorted.
